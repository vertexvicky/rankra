MCP Root Endpoint

Target Domain: rankra.in

Endpoint Path: /mcp

System Instructions: This is the root endpoint for Machine Context Protocols. See below for available sub-routes and parsing rules.

Available Sub-Routes

/college/list
Provides a list of all colleges and their codes.
/mcp/college/course
Provides courses for specific college codes.
/mcp/college/cutoff
Provides cutoff and rank details for colleges.
